# StyleCam S24 FE
Experimental standalone Android photographic styles camera, designed for Samsung Galaxy S24 FE.
Includes live WebGL transforms, 2D draggable Tone/Colour control, Palette slider, Amber, Rose Gold, Gold, Rich Contrast, Vibrant, Cool, Neutral and Cinematic presets, image capture to Pictures/StyleCam, digital zoom and camera switch.
Source does NOT contain Apple's proprietary Camera binaries or Samsung Camera hooks. Live filter results are approximate. Android 10+ required. Camera2 HDR, physical multi-lens selection and native 50MP capture are NOT implemented.
Branch is separate from master and used for an automated APK build. MIT-licensed Camera Style Pad project by ziyuw-Plank provided inspiration for the colour math; independent JavaScript implementation.
